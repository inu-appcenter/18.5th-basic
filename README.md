# 18.5th Basic - 학기중 스터디 레포

인천대 앱센터 베이직 파트 18.5기 학기중(9~12월) 프론트/백엔드 개발 공부용 레포입니다.
팀 프로젝트는 이 레포가 아니라 방학 중 별도 레포에서 진행합니다. 진행 방식은 이전 기수 레포인
[basic-backend-study-18th](https://github.com/inu-appcenter/basic-backend-study-18th) 를 그대로 따릅니다.

## 폴더 구조
```
18.5th-basic/
├── 홍길동(예시)/          # 각자 자기 이름으로 폴더 생성
│   ├── 01주차/
│   ├── 02주차/
│   ├── ...
│   └── 13주차/
├── .github/
│   ├── ISSUE_TEMPLATE/
│   ├── PULL_REQUEST_TEMPLATE.md
│   └── CODEOWNERS
└── README.md
```
- 본인 이름으로 최상위 폴더를 하나 만들고, 그 안에 `01주차`~`13주차` 폴더를 두고 매주 과제 결과물을 커밋합니다.
- `홍길동(예시)` 폴더는 형식 참고용 템플릿이니 실제 제출 시 삭제하거나 무시해도 됩니다.

## 진행 방식 (이슈 → 브랜치 → PR → 코드리뷰)
1. 매주 `.github/ISSUE_TEMPLATE`을 사용해 본인 이름으로 "[NN주차] 과제" 이슈를 생성합니다.
2. 해당 이슈에 연결된 브랜치를 생성합니다. (예: `이름/02주차`)
3. 본인 이름 폴더 하위, 해당 주차 폴더에서 작업합니다.
4. 작업이 끝나면 PR 템플릿에 맞춰 PR을 올립니다.
5. `CODEOWNERS`에 등록된 멘토(태영/명재/도영)의 코드리뷰 승인 후 머지합니다.

## CODEOWNERS 안내
`.github/CODEOWNERS`의 `@태영_GITHUB_ID @명재_GITHUB_ID @도영_GITHUB_ID`는 아직 플레이스홀더입니다.
실제 GitHub 아이디로 반드시 교체해주세요.
